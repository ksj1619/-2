# 약 챙김 — 간단한 개봉일 알림장

작성자: 강승지 / 2026. 11. 23.

설치 없이 `dist/index.html`을 열 수 있습니다. 마이크·알림은 Chrome/Edge에서 HTTPS 또는 localhost로 접속하는 것이 좋습니다.

로컬 실행: 이 폴더에서 `python -m http.server 8080 --directory dist` 실행 후 http://localhost:8080 접속.

## 구현
- 한국어 음성 인식 → 약 이름/종류 추정 → 확인 후 저장. 미지원·인식 실패 시 큰 종류 버튼으로 기록.
- 개봉일 자동 입력, 이름·날짜·사용일수 수정, 삭제.
- 안약 1개월·연고 6개월은 기획서의 시연값. 월말 날짜를 보정해 일수로 표시. 시럽은 직접 입력.
- 포장 유효기간을 입력하면 개봉 후 기한과 비교해 더 이른 날짜 적용.
- 기한 7일 전부터 화면 안내, 기한 당일과 경과 상태 표시. 브라우저 알림 권한 요청.
- 가족 번호 저장, 문자 내용이 입력된 문자 앱 열기. 사용자가 직접 전송.
- 이 기기의 localStorage에 저장. 다른 기기/가족과 동기화되지 않음. 저장소 삭제 시 기록 삭제.

## 시제품 범위
브라우저가 열려 있을 때 1분마다 확인하며, 브라우저가 절전되면 확인이 늦어질 수 있습니다. 앱을 닫은 뒤 예약 푸시, 큰 알림음 보장, 가족 자동 문자 전송은 구현하지 않았습니다. 실제 서비스에는 서버 스케줄러, 푸시 및 SMS 서비스 연동이 필요합니다. 음성 인식은 브라우저/네트워크/마이크 권한에 따라 달라지며 브라우저 제공업체의 음성 서비스를 사용할 수 있습니다.

사용기한 기본값은 의학적으로 검증된 제품 데이터베이스가 아닙니다. 제품 설명 및 약사 안내를 우선해 설정해야 하며, 일회용 제품에 시연 기본값을 적용하면 안 됩니다. 영양제와 정해진 시간의 복용 알림은 이번 최소 구현에 포함하지 않았습니다.

파일: `index.html` 화면, `style.css` 디자인, `core.js` 날짜 계산, `app.js` 동작. 외부 라이브러리 없음.
